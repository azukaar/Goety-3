# Version 3.0.2

## Bug Fixes

This version fixes a critical metadata parsing issue that prevented the mod from loading.

- **Fixed TOML parsing error**: Resolved invalid newline handling in mod metadata credits field that caused mod loading failures

- Mod now loads correctly without TOML parsing exceptions
